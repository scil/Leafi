## The model, restated

- **Who acts.** One child at a time (an enrolled learner, or a guest until confirmed) speaks to Leafi or types on the console. The owner uses the settings page, the CLI and the Obsidian console. The Brain (Claude; magpie, a loopback gateway to any provider; Ollama) picks the next activity from a menu the code computes, unless `policy.sequencer = default` or the 10 % exploration share hands the boundary to the configurable default policy. Per activity kind, code or the Brain fills the content. The study harness constructs, asks (by autonomy band), runs, times, limits and records.
- **States.** The session runs on a terminal latch (`stop`, `lease_lost`, `time_up_session`, `listener_lost_no_console`), one absolute deadline and an epoch. Cycles are `open` or `closed` and own their candidates. `ActivityStatus` is one enum. Items are `new` / `learning` / `known` / `lapsed` / `ignored`, under two mastery modes. Guests are `declined`, `unconfirmed` or crashed. A learner can be `forgetting`. Consents go `granted → used`. Egress attempts go `sending → sent / failed / unknown`. The database moves from `user_version` 4 to 5 through an explicit command.
- **Who decides.** The settings decide sequencing and content ownership. The harness alone decides whether the learner is asked. `egress` decides at send time, from the current settings of every source learner. `LOCAL_MODELS` decides what counts as local. `netguard` backstops with grants. ADR-0013 v2 owns the reading rules.
- **Outsiders.** There is no public surface. The outsiders are the cloud providers that receive payloads, any service that another local program (Anki, Ollama, magpie) forwards data to, and a child at the household PC who can open the settings page (127.0.0.1; a typed confirmation, the parent PIN deferred). Four processes share one SQLite file: study, supervisor, web UI and CLI (rollback journal, `busy_timeout` 5 s).
- **Stack.** Python 3.12 on Windows (asyncio proactor), `httpx` 0.28 (`httpx2` after TD-1), `anthropic` 0.120.2, `aiohttp` (edge-tts), `urllib` (doctor), SQLite 3.49.1 through `sqlite3`. No binding file exists for any of these.

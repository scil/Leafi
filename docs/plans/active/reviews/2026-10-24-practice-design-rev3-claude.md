## Findings

1. **High · P4 provenance: history parts Leafi did not build.** (a) Responses get D2 output provenance; the plan turn carried heard words, so every later response is `derived_from_learner [A]`. With `cloud.text` switched off mid-activity each earlier response is refused (no substitute defined; dropping one breaks tool_use/tool_result pairing, so every remaining turn fails) or sent as is if "model output aside" exempts it ("you said 'box'" leaks). Neither matches P7's test. (b) pydantic-ai's own parts — the `ToolReturnPart` ("Final result processed.") in tool output mode, the `RetryPromptPart` on a re-ask — have no leaves: "unregistered → refused" refuses turn 2 of every activity; whitelisting breaks M7 D4 (Pydantic error text with the input value). Unverified (not installed). Fix: responses as leaves with D2 provenance and a defined substitute (drop with the paired request, or a neutral "[earlier step]"); `output_retries=0`, `brain_call`'s D4 walk owns re-asks; NativeOutput, or Leafi owns the history (#9); test the switch-off through `prepare`.
2. **High · P6/P7 parent interests reach the cloud for a learner with `cloud.text` off.** `_gate` checks `parent` only against `CLOUD_PARENT_TEXT` (default on); the detector runs only on `learner` / `derived_from_learner` (ADR-0018 §3 step 2). "loves riding at Cedar Stables with Lily", entered by a parent for A with `cloud.text` off, leaves with the lists only, no detector — against P7's own test and decision 3's opt-out. Fix: store a parent interest as `derived_from_learner` with sources `[A, 0]` (D2's mixed encoding), so A's `cloud.text` and `CLOUD_PARENT_TEXT` both gate it and the detector runs; test that case.
3. **High · `practice.echo = as_attempt`: the scorer on a whole sentence.** `_score` → `w.pron.score(u.audio_ref, word)` scores the entire recording against one word: a correct echo of a 10-word sentence scores low → `unsure(disagreed)` + `acoustic` + `score < 0.5` → **false `confirmed`** and a pronunciation item. The target hotword also biases toward a pass. It redefines an attempt (ADR-0013 steps 2–3), not in P2's amendments. Fix: never score an echo acoustically (`evidence = none`), or score only the target's time span from word timestamps; an echo cannot reach `confirmed`; amend ADR-0013 step 3 or drop `as_attempt`.
4. **Medium · hard rule 2 and "(l) holds; a parked word the same".** `stop` → `close_cycle(stop)` → a candidate with rows gets `practice_final(rows)`: B ends `unsure(disagreed)`; ADR-0013's table and rule 2 say `unsure(skipped)`. Writing a `skipped` row on stop contradicts step 4 (a cut attempt writes no row) and needs a shielded write in a cancelled scope. A parked word with a fail also ends `disagreed` (the end rule does not run on stop). The gap exists today; parking makes it common. Fix: a stop leaves every word's status to `close_cycle` (rows if any, else skipped); amend the ADR-0013 table cell; the B case in `test_practice_graph` and `test_cycle_candidates`.
5. **Medium · try-first impossible with today's lines.** `practice_retry` = "Your turn - say \"{word}\"" and `practice_intro` speak the word; `Display("say", sentence)` cannot highlight the target; with `ASR_HOTWORDS` an unmodelled attempt gives more false passes. Fix: a prompt line that does not say the word, a highlighted Faces display; hotwords off before modelling.
6. **Medium · P4 per-turn `output_type`.** Each legal subset (and each enum of not-done `m…` ids) is a new schema: a first-use compile inside 3 s; in tool mode it sits in `tools`, before `system`, so every change invalidates the cache; breaks M7 D6/O3 (one byte-stable schema, one compile probe per schema with the owner present). Fix: one fixed `Step` schema per session, the legal set in the turn prompt, code refuses.
7. **Medium · P3 the plan misses `next_activity`.** 6 s − 1 s reserve − `decide` (Haiku ≈ 1–2 s) ≈ 3–3.5 s; the plan (5 × hint + 3 examples + method, JSON) ≈ 600–900 output tokens on `standard`: it times out, `deep` is skipped (`MIN_TIER_S` 4 s), `code` runs — the default `plan_loop` silently runs as `code` in most sessions. P8 must guess `candidate_ids` before `decide` picks them and charges a `standard` unit at every boundary with `practise_errors` on the menu. Fix: size the output now (order, method, hint in the plan; examples lazily in turns, or a `generate` started at activity start); treat P8 as likely, binding by intersecting planned and chosen ids.
8. **Medium · P4/P5 latency and budget per turn.** `feedback` − reserve = 2.0 s on the PC: `fast` 1.5 s fits; `standard` never fits after a `fast` timeout (0.5 s < 2.0 + 0.3): fast-only in practice. A turn before every step with the 0.8 s filler: "…" between most steps; ADR-0017's filler names only `decide` / `generate` (D12 to extend). "The feedback line … while the Brain decides" is sequential as written. 20 turns ≈ 4–6 steps per word cover ≈ 4 words. Re-ask cost: worst case 2.5 units a turn; 20 turns exceed the session's 40. Fix: start the turn concurrently with the feedback line; a turn may return a short sequence ("ModelWord then Attempt"); count turns per `BrainTurn`, cap transmissions per turn, no pydantic-ai retries.
9. **Medium · P4/P9 seam: it amends more of M7 than D18/D19.** D5 (`ModelRequest` has no message list; `LeafiModel` and P9's fallback need multi-turn messages, or the history flattened into sections); D6 (a second breakpoint against "the one statement"); D8 (`PER_CALL_S` for `practice_turn`); D10 (routes); D12 (filler); D21 (a prompt owner per listening step `("act", aid, step)`, `accept_page` on every listen). `destinations.STUDY` and the anthropic purpose set lack `practice_turn` (fails closed at `egress.py:322`), also `TEXT_PURPOSES` for the mediator retry. The design cites rev 4; rev 5 is on disk. Fix: list these; consider the simpler fallback: Leafi owns the history and renders it as sections each request (per-leaf filter, no unregistered parts, a stable schema, no new dependency).
10. **Medium · cancellation and exceptions through pydantic-graph / pydantic-ai (unverified).** `run_activity` maps `StaleInput` → `aborted_stale`, `Terminal` / cancellation → the latch status, other `Exception` → `internal_error`. If pydantic-graph runs nodes in an anyio task group, or pydantic-ai wraps exceptions from `Model.request`, a `Terminal` or `StaleInput` from `s.checkpoint()` arrives as an `ExceptionGroup` → `internal_error`. A node's transaction must not span the score await (`run_in_executor`) or the feedback line. Fix: prototype M1 asserts the activity status for stop, page turn, Ear lost and skip; unwrap exception groups at the graph boundary; order inside a node: awaits, one synchronous transaction, then speech.
11. **Medium · `skip` during a `BrainTurn` or a step with no listen.** Under D12 it goes to the skip queue, consumed only at the next listen; if the Brain chose `Focus(other)` meanwhile, the other word becomes `unsure(skipped)`. Fix: drain the queue when the turn returns and apply it to the word current when the skip was posted (none if none).
12. **Medium · migration 8 incomplete, and after migration 7.** `utterances.kind CHECK(... 'practice','answer')` (`storage.py:248`) rejects `practice_talk` / `practice_echo` (IntegrityError): a table rebuild needed. Every reader of `learner_notes` (`memory` notes, `extract_notes`' cap of 5, the 10-session ageing) must filter on `kind`; the ageing rule is vacuously true for an uncited parent interest. `forget --session`'s `GROUP BY note_id HAVING …` keeps uncited notes (sound). Fix: the CHECK rebuild and `test_migration_8` over `utterances`; exclude `parent` interests from ageing; say whether 7 and 8 merge if M7d has not shipped.
13. **Medium · P7 school relaxation: what changes, the unstated cost.** Learners whose school answer is missing (silence or an unparsed answer at `ask_school`, asked once at enrolment; a term later removed) send text at once (`cloud.text` default on, no `consents` row at enrolment). The school is then replaced only by Presidio; with the detector off or its model missing nothing replaces it, and parent text never gets the detector. Unlisted effects: `remove_term`'s message "… stay off the cloud" becomes false; `notifiers.body` names the learner by surrogate; `ops/checks._schools_answered`; tests asserting the old rule: `test_egress.py:163`, `test_identify.py:52`, `test_privacy_settings.py:80,178` (the design's `test_learner_privacy` does not exist); landing P7 "earlier, alone" conflicts with M7a D1's test "unanswered school … refused". Fix: ask the owner whether to keep the gate while the detector is off or not ready (`cloud_text_allowed = … and (school_answered or detector_active)`); list every affected file and test.
14. **Medium · `WordState` missing fields.** With interleaved words, `_finish_candidate(w, mid, evidence, score)` using a shared last-attempt variable lets `Finish(B)` after A's attempt use A's score: a false or lost `confirmed`. `next_default` needs `modelled`, `hint_given`, `example_used` and a cursor. `Syllables` has no data source (no splitter in the code; no plan field); TTS of fragments ("f…ox") is unreliable. Fix: `last_evidence`, `last_score`, `modelled`, a script cursor; a plan `parts` field checked to join to the word; measure TTS of parts first.
15. **Low · plan fields without a consumer, rule 5 gaps.** `plan` mode ignores `method`; plan hints skip rule 5 ("Look at the picture!", "You're so smart" pass); a target word that is itself a forbidden label ("bad", "smart", "picture") rejects every Hint and Say about it; the check must be whole-token ("badge", "smartphone"). Fix: `method` picks the `next_default` script; rule 5 on plan hints; exempt the target; whole tokens after `norm`.
16. **Low · free text a child hears.** A seven-word denylist misses false hints or definitions, questions for personal information ("what's your teacher's name?"), injection from the page or the child ("end the practice": harmless to status, loses the practice), and unbounded Say/Hint chains with no attempt. Brain lines are mostly `derived_from_learner` → Kokoro while `page` lines may go to edge-tts: the voice switches mid-practice. Fix: cap consecutive non-attempt steps per word (e.g. 3); refuse `?` outside AskMeaning / UseInSentence, digits and emails, second-person questions about people or places; keep the owner-present sample; note the voice switch or use one engine.
17. **Low · `forget --brain-records`.** "Source learners name N" misses rows of N's own sessions whose leaves were all page/system (`[]`): also match `session_id → learner N`; refuse while N has an unended session (`LearnerBusy`). Unstated cost of "until deleted": storage grows with the square of the turns (≈ 20 rows of a growing history per activity, kept forever).
18. **Low · the input for Brain-written interests is undefined.** Nothing renders `practice_talk` utterances in `decide`'s or the post-session observation, so `extract_notes` and the `interest` record have nothing to draw on; guest interest records must be refused; adding `interest` to `decide`'s records changes the session schema and its compile probe (D6).
19. **Low · help text the design contradicts.** `practice.echo`: "Recordings … never leave this computer" vs ADR-0018 §4.1's remote teacher with a per-item consent; `practice.history_days`: "with names and the school replaced" vs P7; `practice.planner`: "falls back to the fixed routine" while a failed turn falls back to `next_default`, not `code`.
20. **Low · smaller gaps.** ADR-0013's "in the order ADR-0017 gives (Difficulty weight, then position)" must be amended too; `Focus` shows the sentence only the first time, so after `Focus(C)` → `Focus(B)` Faces still shows C's; "yes" / "no" in AskMeaning parse as controls (`controls.parse`) and get the spoken no-op: route them as talk in ungraded steps.
21. **Low · pydantic facts not checked** (not installed): per-run `output_type`; `Model.request(messages, settings, params)` and `ModelRequestParameters` (output tools vs native); parts as keys (dataclasses with `eq=True` are unhashable, `UserPromptPart` has no id: `state.leaves[part_id]` needs Leafi's own id); `ToolReturnPart` / `RetryPromptPart` content; whether output retries call `request` again; exception wrapping in pydantic-graph; `PYDANTIC_AI_NO_BANNER`; the 2.61.0 versions; persistence removal and runtime return-type checks; `BaseNode` vs the step-based `GraphBuilder` (the research mixes them); `httpx` at import; whether `genai-prices` fetches (netguard would refuse). M8 should cover each.

## Sound

The egress seam (no provider SDK inside pydantic-ai; token, reservation and audit stay with `brain_call`'s backend); the two-attempt cap (no third attempt on any path); page turn and never-attempted words staying `candidate` with `close_cycle`'s statuses; no graph persistence, recovery from `practices`; two fail-safe fallback levels; `code` untouched so `test_practice` stays meaningful; AskMeaning and UseInSentence never graded; audio never a payload; the research's claim that decisions 2–5 already hold (`KEYS["cloud.text"]` on, `from_row` forces guests off); an unknown purpose fails closed at the allow-list; `forget --session` / `--learner` cover `utterances` and `brain_calls` by session, and the note query keeps uncited notes.

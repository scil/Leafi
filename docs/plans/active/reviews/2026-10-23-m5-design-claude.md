# M5 egress design — fresh Claude reviewer (round 1)

Reviewer: a fresh Claude agent (general-purpose, no context from the authoring session) on `reviews/prompts/m5-design.md`, 2026-10-23. Independent of the codex and code-plan-review rounds.

1. **High — D5/D8 egress_log CHECKs.** `storage.py:344` has no `notify`; `CHECK((purpose='ops') = (learner_id IS NULL))` requires a learner for study purposes. Amend migration 5 if the owner's file is unmigrated, else migration 6 (ADR-0018 §7.2 rebuild), or reuse an existing purpose (owner).
2. **High — D12 `REDACT_TERMS` migration.** `kind='term'` fails `household_terms.kind CHECK(name|school|other)`; the unique `term COLLATE NOCASE` index throws when a term is already a learner name; under D10 a child's name stored as `other` becomes `[place]`. Classify each term (default `name`), `INSERT OR IGNORE`, test.
3. **High — M5a–M5f ordering.** M5a installs the guard everywhere with no grants: Claude, edge-tts, Telegram, Bark, Open Library and `doctor --download` are refused until M5d (the suite stays green because tests do not install it). M5c removes `REDACT_TERMS` while `tts/edge.py:33` and `study/coach.py:66` still redact with it until M5d: nothing redacted in between. Ship the guard log-only in M5a (`LEAFI_NO_NETWORK` still enforcing) and enforce in M5d with the callers; keep `REDACT_TERMS` until callers use `prepare`.
4. **High — D10 CJK.** `\b` never matches inside CJK text; zh lines go to edge-tts by default; a Chinese name is sent unreplaced. Hyphenated names leak ("Ann-Marie" with "Ann" listed → "Jordan-Marie"). Script-aware boundaries (substring for CJK, word boundary for Latin) with tests.
5. **High — D13 fail-open default.** `Inputs.say(text, provenance=("system", []))` sends any unannotated line to edge-tts: `review_prompt_eases front=card.front` (activities.py:448, card text may be `derived_from_learner`), `identify.py:107` (speaks learner names), the `Talk` protocol (state.py:22) has no provenance; the ADR §3 TTS cache sidecar is missing. Provenance a required keyword; a `line()`'s class from its kwargs' provenance; a test enumerating every say/line call site; the sidecar.
6. **Medium — D11/D13 contradiction; edge-tts speaking surrogates.** D13 routes lines "in which the detector finds a name" locally but D11 runs it only on learner text; system/page lines with list terms go to edge-tts pseudonymised ("Who's reading today? Mia, Leo" spoken "Jordan, Riley"; a book character sharing a learner's name is misread aloud). ADR §2: with `local`, edge-tts "never speaks a surrogate name". Route any line matching a list term (or detected entity) to local TTS whatever its class.
7. **Medium — D10 surrogates.** `HMAC mod 200` with ~10 person terms ≈ 20 % collision; payload-dependent skip breaks stability across a multi-turn context; neutral names that are words (River, Sky, Sage, Robin) make a case-insensitive reverse map turn "the river" into "the Mia". Assign once per household by deterministic probing, stored; exclude dictionary words; reverse-map case-sensitively, whole-word, only surrogates actually sent; a page word that is a surrogate → another surrogate for that conversation, recorded.
8. **Medium — D6/D7 token lookup.** `(host, H)` keys collide for identical bodies (the same ops alert twice, a repeated `word` request); the retry slot is usable by any request with the same H, so `claude.py`'s own two-attempt loop (51–62, kept by D17) uses it, against ADR §2. Carry the token id in a request extension or stripped header and check H against it; the retry slot only for the mediator's internal retry; remove the adapter loop in M5d.
9. **Medium — D11 Presidio download.** `SpacyNlpEngine` calls `spacy.cli.download` (pip, a subprocess outside the guard) when `model_name` is not an installed package. Load spaCy yourself and wrap it in an `NlpEngine`; test that no subprocess starts. "Model missing → detector off" silently weakens the default-on: prefer refusing `learner` text to the cloud while the detector is on and the model absent, or ask the owner.
10. **Medium — D2/D3 `lan` bypasses gateway ports.** A `lan` address passes on any port; if a `lan` host is this machine's LAN IP or Ollama/magpie bind `0.0.0.0`, `<lan-ip>:11434` reaches the gateway without a grant. `LEAFI_NO_NETWORK` used to refuse LAN (netguard.py:34); under D2 a test can reach the camera. Protect gateway ports on every local interface address; `lan` as (address, port); `LEAFI_NO_NETWORK` refuses `lan` too.
11. **Medium — D2/D15/D16 assume async; doctor is synchronous.** `doctor.download` is sync; `snapshot_download` uses a `ThreadPoolExecutor` (no contextvars); rapidocr uses `requests`; "`asyncio.to_thread` under a resolution grant" does not exist in sync code. A synchronous mediating transport opening the grant and resolving inside `handle_request` in the worker thread; check whether huggingface_hub 1.16.1 passes `follow_redirects=True` per request.
12. **Medium — D15 environment.** Setting env in `leafi/__init__.py` fails `test_architecture.py::test_no_environment_reads_outside_core_config`; `HF_HUB_OFFLINE` is read at hub import, so lifting it works only before any hub import (openpronounce, `doctor.report`). Explicit test exemption; set before any hub import or run the download in a child process.
13. **Medium — D12 `cloud.text` location.** `study/harness/settings.py` is not importable by `leafi.privacy` (D1); in `SPEC`, `settings.save()` would change it with no typed confirmation and no `consents` row; guests must be off whatever is stored. Privacy keys in `learner_store` with their own writer that writes `consents`; `SPEC` rejects them; the filter reads `kind`.
14. **Low — D7/D5 notify without a learner.** `Hub.notify(title, body)` carries no learner or session; the CHECK requires one. Extend the `Notifier` port.
15. **Low — supervisor probes.** The Ollama tags probe (and a magpie probe) hit gateway ports: `ops` grants with a fixed GET schema, not "loopback" (ADR §7.3).
16. **Low — D8 key creation race.** Read after `O_EXCL` before 32 bytes: write a temp file and `os.link` it into place; include the key in `leafi backup`.
17. **Low — D9 two refusal shapes.** In library mode the guard raises `NetworkDenied` inside aiohttp, not a 403: `TtsService` must catch it and show on Faces.
18. **Low — other.** `envedit`'s CLI path is `trusted_confirm=True` and console buttons are non-interactive (the CLI "typed confirmation" needs its own design); `alias_age_band` set once goes stale — compute from `birth_year` at prepare; UDP `sendto` / `create_datagram_endpoint` unguarded — a blocking audit hook on `socket.connect` / `sendto` / `getaddrinfo` complements the patches (the proactor's `ConnectEx` still needs `sock_connect`).

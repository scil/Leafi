## Findings

1. **High · P4 narrowed `output_type=legal_steps(state)`.** The legal set changes almost every turn, so the schema does too: against ADR-0017 §5 ("schemas … constant within a session per (purpose, tier)") and M7 D6 (byte-stable, `test_brain_schemas`, the 24 h compiled-schema cache); each subset may pay grammar compilation, fatal in a 2 s window; in tool mode the output tools head the cache prefix, so the plan-turn breakpoint misses most turns. Inputs: Focus(B) → turn 2 offers {Attempt, ModelWord, …, no Finish}; after the fail turn 3 offers {…, Finish}. Fix: one fixed `Step` schema per session, legality in code only, the legal set as text in the turn prompt.
2. **High · P4 "no registered leaves (model output aside) → refused".** pydantic-ai adds parts Leafi never registers: the system / instructions part, the `ToolReturnPart` after an output tool call, and on a validation failure a `RetryPromptPart` with Pydantic's error text including `input_value`. Turn 1 valid → synthetic tool-return appended → turn 2 finds no leaves → refused, and every later turn: `plan_loop` silently becomes `next_default` after one turn. An invalid output's `retries=1` re-ask carries Pydantic text (M7 D4 forbids it): it leaks, or is refused and poisons the history. Fix: `LeafiModel` renders only from Leafi's own records keyed by turn index, not by pydantic-ai part identity; synthetic parts map to fixed `system` constants; retry text replaced by D4 codes, or `retries=0` with `brain_call` owning the re-ask; the prototype tests this two-turn history and a forced invalid turn.
3. **High · P4 the M7 port has no multi-turn shape.** M7 D5's `ModelRequest` is `system + sections` (one user message); D6 allows one breakpoint on the system block; the Claude backend, egress's body comparison and the `api_schema` tests assume it. "Converts the message list into `ModelRequest`" needs either flattening the conversation into sections (the Brain loses its own assistant turns; no plan-turn breakpoint) or extending `ModelRequest`, the backends and D6/D11 with turns and a second breakpoint — the design names neither. P9's fallback needs the same extension, so it is real but not cheaper. Fix: decide the port change and list it as an M7 amendment (D5, D6, D11) with tests.
4. **Medium · P4 two validators, two re-ask paths.** `brain_call`'s `check_shape` makes `invalid` → next tier (M7 D8); pydantic-ai `retries=1` re-asks after `request` returns; together: fast invalid → standard → pydantic re-ask → a new walk from fast, each charged, none fitting the moment. `limits.practice_turns` counts turns, the ledger transmissions; which a re-ask uses is unstated. Fix: one owner (`brain_call` validates with `retries=0`, or the reverse); state what a re-ask costs.
5. **High · P7 "school no longer required": the detector does not replace what the gate held back.** Probe, `en_core_web_sm` 3.8.0 through Leafi's `Detector`: "at st marys school we read books" → nothing; "we went to riverside primary today" → nothing; "my teacher at oakfield is nice" → nothing; "it means like my friend tom has a box" → nothing; "MY FRIEND TOM HAS A BOX AT OAKFIELD SCHOOL" → only "BOX" (ORG); "I go to Saint Mary's Primary School" → "Saint Mary's" (LOC) + "Primary School" (ORG). Parakeet output is cased (helps for voice); typed lines and lower-cased fragments are not. Detector off or model missing (list-only) → an unanswered school leaves verbatim. "Sent pseudonymised by the lists and the detector" overstates it; rev 3 multiplies free speech that may name a school. Unstated: `remove_term` of a school now leaves the learner's words flowing unreplaced; sites not listed: `cli.py` setup text 454–462 ("keeps their own words off the cloud"), `remove_term`'s effect message, the `settings.py` docstring, `doctor.py:51`. Fix: state the cost in ADR-0018; keep `alerts` / `doctor` as a loud warning; `test_privacy` covers lower case and detector-off as known limits.
6. **Medium-High · P3/P4/P8 latency.** Turn on the PC: feedback 3 s − reserve 1.0 = 2.0 s; fast `PER_CALL` 1.5 s; after a fast timeout 0.5 − 0.3 < `MIN_TIER_S[standard]` 2.0, and even at t = 0, 2.0 − 0.3 = 1.7 < 2.0: **on the PC `standard` is never eligible**, the route is fast-only. Camera: 6 − 3.5 = 2.5 s, standard only after an immediate fast failure. A `retries=1` re-ask never fits. Haiku with a growing history will often pass 0.8 s: a filler at many of up to 20 boundaries. P5's last bullet contradicts itself: the feedback line "before the next BrainTurn … while the Brain decides" — sequential means TTS + up to 2 s gap; concurrent means the 0.8 s filler collides with it. Plan: `generate` at `normal` is `standard → deep`, `PER_CALL` 4 s, in the `next_activity` moment shared with `decide` (≈ 2–3 s left): five words × 3 examples + hints on Sonnet will usually miss, so `planner_used = code` most of the time; P8 still caps it at ≈ 5 s. Fix: start the activity on `next_default` for the first word and let the plan arrive inside it, or route the plan to `fast`; make P8 the default; state turns are fast-only; define the feedback-line / filler order.
7. **Medium · P5 rule 2 vs `close_cycle`: `stop` on a revisited word.** A passes after TryFirst → row (1, matched) → `withdrawn(practice)`. B fails → row (1, disagreed), parked; Focus(B); Attempt; `stop` during the listen → no row; the activity ends `stopped`; nothing touches B; `finalize` → `close_cycle(stop)` → B has rows → `practice_final([disagreed])` → **`unsure(disagreed)`**; C (no rows) → `unsure(skipped)`. The design and ADR-0013's control table say the current word → `unsure(skipped)`; they differ in Difficulties (0.3 vs 0). Park/revisit makes this common; under `code` only across a page turn. Fix: decide which is right (keeping the fail is defensible), write it into ADR-0013 → Control precedence, test it. The other walks hold: page turn during AskMeaning → B stays `candidate` with 1 row, `close_cycle(next_reading)` → `unsure(disagreed)`; turn budget out with B current → `next_default` → ModelWord, Hint, Attempt 2 → done → Finish; C then Focused by the script. No third attempt possible (the `practices` CHECK also enforces it).
8. **Medium · `WordState.used` "any activity" and Finish.** (a) A word with one row from an earlier page-turned practice, never Focused in this activity, has used ≥ 1, so EndPractice Finishes it without the second try `code` would give; "never attempted" must say "in this activity" or "ever". (b) `_finish_candidate(w, mid, evidence, score)` needs the last attempt's evidence and score; `practices` stores no score and `WordState` has no field: a word attempted, parked and Finished by the end rule gets `evidence = none`, so `confirmed` is impossible for every parked word. Fix: `last_evidence`, `last_score` and a `modelled` flag (which `next_default`'s "ModelWord (if not yet)" also needs) in `WordState`; define the end rule on attempts made in this activity.
9. **Medium-High · `practice.echo = as_attempt` and the scorer.** `_score` runs `openpronounce.compare_audio_with_text(whole clip, expected=word)`: for an echo the clip is a sentence of up to 12 words against one word, so the score is low by construction. "The box is on the bed." echoed with "bocks" → `fail` → `unsure(disagreed)`, acoustic, below `PRON_CONFIRM_BELOW` → **`confirmed`**, a `pronunciation` item and a weight-1.0 encounter the evidence does not support. `fail` needs every heard word ≥ 0.5, so sentence echoes skew to `unclear`; the hotword rule for an echo stream is unstated; ADR-0013 step 3 defines an attempt as a retry of the word and is not amended. Fix: echo attempts with `evidence = none`, or score only the aligned word segment; amend ADR-0013 step 3.
10. **Medium · migration 8 misses `utterances.kind`.** `CHECK IN ('reading','control','question','correction','practice','answer')`: `practice_talk` / `practice_echo` raise IntegrityError at the first AskMeaning. SQLite needs a table rebuild, sequenced 6 → 7 (M7) → 8. Fix: list it in migration 8 with a rebuild test.
11. **Medium · P4/P7 `cloud.text` off mid-activity.** The re-render covers Leafi's leaves; the Brain's own earlier outputs (Say lines, hints, tool-call arguments quoting "box") are `derived_from_learner` by D2, so `_gate` refuses every later `prepare`: safe, but the claim "earlier heard words go out as categories" is false and the test passes vacuously or fails. Treating "model output aside" as plain strings bypasses `_gate` (only `Text` is gated) and leaks. Fix: on a privacy-version change restart the conversation (re-render the plan, drop model parts, carry a Leafi-written summary of the step results); test the leak path and the restart.
12. **Medium · skip during a `BrainTurn` and during playback.** Under M7 D12/D21 a `skip` said while the Brain thinks goes to the skip queue: B current, "skip" while the turn chooses Focus(C) → the next listen (C's Attempt) runs `take_skip()` → C gets the `skipped` row instead of B. During rev 3's longer playback steps, `skip` only cuts the line and the word continues. Fix: a skip owned by a `BrainTurn` or a teaching step applies to the word current at that moment; write it into D21's owner table; test it.
13. **Medium · P5 rule 5, the free-text check.** Not applied to plan `hint`s (≤ 150, no label check) or examples: "The stupid dog ran." passes. It misses ADR-0013's framing rule (until the false-alarm budget is met practice is "let's practise", never "wrong"): "That's wrong" passes. It cannot catch false phonics ("rhymes with cat" for "cut"), revealing the word before a TryFirst attempt, or content steered by injected page text or the child's AskMeaning words ("tell me a scary story" → a two-sentence scary line passes). Fix: one check on every spoken Brain string (plan hints, examples, Hint, Say); add `wrong`, `mistake`, `incorrect` …; add the injection cases to D20's measured checks.
14. **Medium · P7 `forget --brain-records` by source learners.** For a learner with `cloud.text` off, or a guest, the sent leaves are page/system (expected words of N's misreadings, outcomes) and `payload_source_learners = []`: those rows describe N's errors and survive the delete. Fix: also select by `brain_calls.session_id → reading_sessions.learner_id = N`; refuse while N's session is live (`LearnerBusy`), since it edits `data/evals/` too (M7 R8's race).
15. **Low-Medium · P6 interests.** "Age out like notes" written as a citation query is vacuously true for an uncited parent interest, which then drops out of `memory` at once: exclude `provenance_class = 'parent'`. Guests get no Brain-written interests (`extract_notes` skips them; the `decide` record kind must too). `forget --session` / `--learner` stay complete.
16. **Low-Medium · retention cancelled: unstated growth.** Each turn re-sends the history and `brain_calls.payload` keeps the whole prepared JSON: ≈ 20 × 15–25 KB, 0.3–0.5 MB per activity, hundreds of MB a year, kept forever and copied by every backup; `decision_records` keep withheld leaves too (M7 S3). Fix: state the volume in ADR-0018 §4.3, or store each turn's delta with a reference to the previous row.
17. **Low-Medium · ledger cost.** Plan (1–3) + 20 × 0.25 (+ re-asks) ≈ 6–11 of the session's 40 units per practice; three or four practices starve `decide`. An early EndPractice with no attempt leaves every candidate open and the next boundary re-offers with a freshly charged plan (D14's cache is per boundary). Fix: state the cost; after an EndPractice with zero attempts drop `practise_errors` for the rest of the cycle.
18. **Low · node transactions.** "Each node commits in one transaction" needs "all awaits (listen, `_score` in an executor) before the transaction; the write synchronous": today `_store_utterance`, then `await _score`, then `record_practice`, so a stop during `_score` leaves a `practice` utterance without a `practices` row. `next_default` must be a subset of `legal_steps`, or with teaching steps illegal (< 6 s left) and ModelWord not done the default proposes ModelWord, the refusal replaces it with the same default, and the loop never ends; test it.
19. **Low · P9.** `pydantic-ai-slim` very likely imports `httpx` (unchecked); the alias must cover whatever it touches at import; add a `test_netguard` case running a full mock turn with pydantic-ai imported (no socket from logfire, opentelemetry or price data).

## The model, restated

- **Who acts.** One child at a time (an enrolled learner, or a guest until confirmed); the parent through the web UI (a new Learners tab with a PIN, beside the `.env` page) and the CLI; the Brain through `leafi.privacy.egress`, which now owns every non-loopback client, including operational traffic (`ops`) and model downloads; the supervisor, the web UI, the CLI and one study process all open the same SQLite file, and each one runs `Store.migrate()` when it opens it.
- **States added by the revision.** `learners.kind ∈ {learner, guest, anonymous}`; a guest's reason (`declined` / `unconfirmed`) and `guest_expires_at` (one week); `corrections.source_learner_id` and `forgotten`; `provenance_class` + `source_learners` on every stored text column that can reach a payload; consent `granted → used`; `ActivityStatus` with `store_busy`; destination classes study / `ops` / `lan`; grants by `(host, resolved addresses, port)`.
- **Who decides.** `egress` decides at send time from current settings. `LOCAL_MODELS` decides what counts as local, and `HOUSEHOLD_TZ` decides what a day is. The parent PIN guards a listed set of declassifying actions. One learner-scoped store API writes the direct-owner tables. A rebuild migration step re-keys the schema.
- **Outsiders.** Unchanged from the first pass: no public surface. "An outsider" is a cloud provider that receives payloads, or a child at the household PC who opens the parent's pages (127.0.0.1, no authentication apart from the new PIN).

## Part 2 — findings

1. **Medium — D2: sync TLS sockets escape the per-grant set.** `SSLContext.wrap_socket` → `SSLSocket._create` takes the fd and `detach()`es the recorded socket (fd −1); revocation's shutdown/close does nothing to the live TLS connection. Patch `wrap_socket` / `SSLSocket._create` to move membership; test with a retained TLS socket. Asyncio is unaffected.
2. **Medium — D2: `close()` from the revoking context is unsafe** for sockets owned by an event loop (Proactor WinError 10038, selector fd reuse; `TransportSocket` has no `close`) or blocked in another thread. Revocation calls only `shutdown(SHUT_RDWR)`; closing stays with the owner or goes through `loop.call_soon_threadsafe(transport.abort)`. State that the audit hook does not see Proactor `ConnectEx`. A leaked, never-closed response needs a hard revocation ceiling (the deadline).
3. **Medium — D5/S1: "delivery finished" marker undefined.** Add `reading_sessions.post_done_at` to migration 6, written after deliver and extract; startup recovery sets it for sessions whose owner process is dead; sweeper and forget test it. Name the move of `finalize_guest` (loop.py:215) out of `finalize`.
4. **Medium — D15: HF continuation capabilities vs huggingface_hub 1.16.1.** (a) `http_get` resumes with a new `Range` on the same URL up to 5 times and re-sends on 429 (file_download.py:439-458): bind capabilities to (URL, file, method) until the file's deadline, repeat use only for a forward `Range` or a 429 retry, capped. (b) `snapshot_download` resolves with `repo_info.sha`: pin `op.HF_REPOS` to commit shas and pass the sha. (c) List the CDN hosts; decide `follow_redirects` on Leafi's factory (the default factory sets it True; the relative-redirect helper sets it off per call).
5. **Medium — D7/D8/D12: one shared `Store` connection, not thread-safe**; `transaction()` joins via an unlocked `_depth` (storage.py:556-574), and is `BEGIN IMMEDIATE` (no read snapshot primitive). Egress owns its own connection per thread or behind a lock, with a deferred-read snapshot helper; reservations use the busy-retry helper and fail closed with 403.
6. **Medium — D10/S19: school answer.** (a) A `school` term has no learner column and siblings share it: store `privacy.school` (`none` or a term id) in learner settings through the privacy writer. (b) Voice enrolment in `identify` (identify.py:125-128): an unanswered learner is created, cloud learner text refused, doctor lists them. (c) The ASR answer is unverified: doctor and the console show it for the owner to confirm. (d) doctor.py:136 tells owners to put schools in `REDACT_TERMS`; migrate runs from a console button without stdin: a non-interactive default, and a school command that upgrades an existing term's kind and links it.
7. **Low/Medium — D12: a stale fingerprint refuses only learner-derived text**, but `CLOUD_PARENT_TEXT` governs `parent` text: refuse every study-purpose transmission. Parse `.env` with the same `dotenv_values` and path as Settings.
8. **Medium — D19: `migrate_file` rebuilds v4 to the latest `SCHEMA`** (storage.py:763-797), so after M5a v4 → v6 skips step 6's data actions. Freeze `SCHEMA_V5`, run step 6 after it (or share data-action functions); fresh `SCHEMA` inserts the seed row; the equality test covers seed rows. State the rollout cost: every v5 file refuses to open from M5a until the owner runs migrate.
9. **Low — D6 headers.** Name the transport headers (`x-api-key`, `host`, `accept`, `accept-encoding`, `connection`, `content-length`); `X-Stainless-OS` / `-Arch` values like `other:<machine>`; build the client with `open_telemetry={"traces": False, "propagation": False}` (`traceparent` / `baggage`) and test it; compare parsed values type-strictly (`True == 1 == 1.0`).
10. **Low — D10/S24: `forget_learner` inserts only `display_name` guarded by `NOT EXISTS`** (records.py:270-272): set `former_learner_id` on an existing unlinked row or record the conflict; name the entity key of a plain household name term.
11. **Low — admission:** version reread and reservation in one `BEGIN IMMEDIATE`. `latch.versions` returns `(settings_version, 0)` (loop.py:275): say whether a `cloud.text` flip should fire `on_settings_change`.
12. **Low — bootstrap coverage:** add `scripts/evals/*`; confirm `agent/webui`'s effective-state display needs only file checks.

## Sound

Two seams, the registry, prepare-then-encode; atomic claim with private retry; strict parse of the SDK body and sending those bytes (the SDK sends no idempotency header); grants until stream close with no keep-alive; the `.env` fingerprint; reservation-then-outcome with owner recovery; `former:<id>`; refusing unanswered learners; the HF child; detector reporting in M5c; unconditional media refusal; the rollout order.

## Verdict

No High: nothing lets learner text out unprotected. Design holes to fix first: items 3, 6a, 8 and 1–2 before M5a; item 4 before M5b's HF adapter. Items 5, 7, 9–12 are implementation detail for the code and its tests.

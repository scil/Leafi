## Findings

1. **High · P4 "model output aside".** Earlier model responses are re-sent on every request; under M7 D2 they are `derived_from_learner` once a heard word was sent and may quote it. As plain strings they skip `_gate` (`_plain_strings`), so after `cloud.text` is switched off mid-activity learner-derived text still leaves (defeats P4's re-render and test M7); wrapped as `Text` with provenance, `_gate` refuses the whole request and every later turn falls to `next_default` (D3 has no substitute for a response). Fix: store each response's output provenance and its structured step; on re-render replace a response that may no longer leave by a fixed `system` stand-in (`[step: Hint]`), keeping role and tool pairing valid; test: off between turns 2 and 3 → no earlier model text in request 3.
2. **High · P4 the model seam (H1.1, H1.2, I1).** M7's `ModelRequest` is `system` + `sections` (one user message) + one `schema`: no message list, no assistant turns, no tools, so "converts the message list into M7's `ModelRequest`" has no target. pydantic-ai adds parts Leafi never registered: in tool-output mode a `ToolReturnPart` ("Final result processed.") follows each answer, so "unregistered part → refused" refuses every turn after the first; with `retries=1` a `RetryPromptPart` carries Pydantic error text, often with the `input` value (breaks M7 D4's codes-only rule; may be learner-derived). pydantic-ai's re-ask and M7 D8's `invalid → next tier` both own invalid retry: up to 4 transmissions per turn in a 3 s moment. The note claims it amends M7 only in D18/D19, but it changes D5, D6 (the single breakpoint `test_brain_call` asserts) and D4. Fix: extend `ModelRequest` with `messages` and `tools` in the M7 design itself; list every Agent option with its value (output mode: prefer `NativeOutput` or prompted; `retries`/`output_retries` 0 so M7's walk alone owns invalid; `instructions` vs `system_prompt` with history; `usage_limits`; `instrument`); register library-generated part kinds as fixed `system` leaves; prototype M8 asserts the part kinds per turn.
3. **High/Medium · P4 `output_type=legal_steps(state)` (H1.3, K3.1).** The schema changes most turns (`Focus(mid)` id sets); tools render before system, so the "breakpoint after the plan turn" misses nearly every turn; each variant may pay a first-use grammar compile (O3 avoided it with a byte-identical `decide`); `test_brain_schemas`' "byte-identical when built twice" cannot describe a per-state schema. Fix: one fixed `Step` schema per `PROMPT_VERSION` (ids as strings); the legal set in the turn prompt as text; code refuses an illegal choice (`refused: <code>` exists).
4. **Medium/High · P5 hub "every Step → BrainTurn" (K3.1).** A Brain round trip between every two utterances (`ModelWord` → wait → `Hint` → wait → `Attempt`), up to 20 per activity, the 0.8 s filler on most; on the camera Mouth each short line pays its own clip start-up. Fix: a turn returns a short step sequence ending at the next listen (or `Park` / `Finish` / `EndPractice`), so the Brain is asked only on new evidence; one budget per perceived moment, measured on the camera Mouth.
5. **Medium/High · P3, P8 the plan inside `next_activity`.** The plan runs after `decide` in one 6 s moment, but M4 measures the plan alone; with `decide` at `fast` (≤ 2 s) and the plan at `standard → deep` it will often miss. When the moment is spent, M7 D14 rejects a brain-owned kind ("not available now"), removing `practise_errors` from the offer, while P1 says "no plan → `code`". Fix: a missing plan constructs with `code` content and never rejects the kind; M4 measures `decide` then the plan in one moment, deciding P8.
6. **Medium · P5 rule 4, `practice.echo = as_attempt` (G4.2, B1.5, F1.1).** `utterances.kind` is `CHECK IN ('reading','control','question','correction','practice','answer')`; migration 8 changes only `learner_notes`, so the first `practice_talk` / `practice_echo` insert fails. `legal_steps` gates only `Attempt` on `used < 2`: an `as_attempt` echo at `used = 2` inserts `attempt = 3` against `CHECK(attempt BETWEEN 1 AND 2)` mid-activity; at `used = 1` it silently ends the word. Fix: migration 8 also rebuilds the `utterances` CHECK; an `as_attempt` echo is scored only while `used < 2`, else unscored; its grading over a sentence and its hotword go into ADR-0013 → Practice.
7. **Medium · P2 "the learner may try first" (F1.4, K2.1).** `practice_retry` = "Your turn - say \"{word}\"" speaks the word; `practice_intro` says "Listen first."; Faces shows the sentence without marking the target, so the child does not know which word; with `ASR_HOTWORDS` on, the target hotword biases a fresh misread toward `pass` and withdraws a real miscue. Fix: a try-first phrase set that never names the word in TTS; Faces marks the target; state whether the hotword applies before modelling.
8. **Medium · P5 `WordState` with `Park` / `Finish` / the end rule (F1.1).** `_finish_candidate` takes `evidence` and `score` from the last attempt's locals; `practices` stores `evidence` but no score; `WordState` holds neither. A word attempted, parked and finished later can never become `confirmed` — Difficulties and pronunciation items shift away from Brain planners. Fix: persist the score on `practices` (migration 8), or keep `(evidence, score)` in `WordState`, and state which attempt's score `Finish` uses.
9. **Medium · P5 rule 3, `EndPractice` "when your child seems tired" (F2.1).** An unattempted word stays `candidate`; `ledger.cycle_errors_left` counts only candidates with `practices` rows, so `menu.allowed` keeps `practise_errors` and default step 3 re-offers it at the next boundary: a new charged plan for a child judged tired, until `activities_per_cycle`. Fix (owner): `EndPractice` records a reason and removes `practise_errors` from this cycle's menu; or the end rule settles unattempted words `unsure(not_practised)` as `close_cycle` would.
10. **Medium · `Finish` after ≥ 1 attempt (K2.1).** A Brain finishing after one `fail` records `unsure(disagreed)` (Difficulty weight 0.3, toward `watch`) where `code` would have given a second try that might pass: the planner's choice becomes evidence about the child and biases the planner comparison. Fix (owner): record that the planner ended the word and exclude it from the comparison, or keep the second attempt unless `skip`, `idle` or time ended it.
11. **Medium · P5 `AskMeaning`, `UseInSentence`, unscored `Echo` (I2.3, C3.3).** The child's free speech, and any voice the ASR picks up in the room (a sibling, the TV, a parent), goes to the cloud — broader than decision 2's "a misread 'box'"; with the history re-sent every turn and `brain_calls` kept until deleted, each utterance is stored up to ~20 times indefinitely; the `practice.planner` help text does not say answers and sentences are sent. Fix: its own egress-table row and help line; a separate key, or only a local summary (target used yes/no, word count) instead of the transcript.
12. **Medium · P7 "school no longer required" (G4.1).** Paths the gate was blocking, none listed: (a) never answered; (b) `remove_term` of a school — its effect "has no school answer now" now means the school name leaves in clear; (c) `PRIVACY_NAME_DETECTOR` off — nothing replaces the school; (d) detector on, but spaCy ORGANIZATION recall on lower-cased ASR text is unmeasured. The `practice.history_days` help text ("with names and the school replaced") becomes false for an unanswered school. Fix: keep the gate when the detector is off; reword `remove_term`'s effect, `doctor`, the help text; measure ORG recall on ASR-cased child speech.
13. **Medium/Low · P4 budget.** 20 turns × 0.25 plus `standard` escalations (1.0) and re-asks per activity, several practices a session, against `limits.brain_calls_per_session` 40: `decide` and `generate` can be starved late in a session; whether an escalation or re-ask counts as a "turn" is unstated. Fix: a per-activity unit cap and a reserve for `decide`; a turn = one `agent.run`.
14. **Low · P1 `plan` mode, `next_default` (F1.4).** The plan's per-word `method` has no consumer: `next_default` always runs ModelWord → Hint → Attempt → Example; paid for and ignored under `plan` and every fallback. Fix: `next_default` dispatches on `method`.
15. **Low · P5 rule 2 covers listens only (F1.1).** Unstated: `skip` during a teaching step's playback (M7 D12: cuts the line only) and during a `BrainTurn` (M7 D12: the skip queue); a child saying "skip" during a hint expects the word skipped. Fix: state both.
16. **Low · P7 `forget --brain-records` (B2, I1).** Unstated: the `LearnerBusy` fence while a session writes; rows with several source learners deleted too (consistent with `_purge_derived`); `--before` on `data/evals/` files; and "files under `data/evals/`" contradicts M7 D19, which moved decision records into `leafi.db`. Fix: state all four.
17. **Low (H6.1, H6.2).** No architecture test confines `pydantic_ai` / `pydantic_graph` imports and types (`ModelMessage` in `PracticeState`) to the practice module; P9's fallback has no contract test shared with the Agent path.
18. **Low (G4.3, K2.1).** P6's `kind` column: every existing reader of `learner_notes` (the `memory` notes, `extract_notes`' input, the 10-session ageing, the settings page) must say whether it filters on `kind`. A Brain-written interest from ASR'd free speech ("I hate dinosaurs" → dinosaurs) is a judgement; acceptable if stated (visible, deletable).
19. **Low (H5.1).** `report practice` and `learner interests list` are recurring operations with no console step; only `forget --brain-records` is scheduled (M10).

Outside the catalog: improvised lines spoken to a child mid-session (`Say`, `Example(text)`, `Hint(text)`) pass a lexical check only; sampling happens only in P5's owner-present check.

## Decisions only the owner can make

- Whether the child's free speech and room transcripts (AskMeaning, UseInSentence, Echo) go to the cloud and are kept indefinitely, ~20 copies each (#11). Recommended: a local summary only, or its own opt-in key.
- What `EndPractice` does with unattempted words; re-offer in the same cycle (#9). Recommended: no re-offer this cycle.
- Whether a planner-ended single failed attempt counts as `disagreed` (#10). Recommended: mark it, exclude from comparisons.
- Whether the unanswered-school relaxation holds with the name detector off (#12). Recommended: keep the gate then.
- Whether improvised spoken content is acceptable with lexical checks only, or Brain planners speak only plan-time content.
- Unstated costs of the 2026-10-24 decisions: indefinite retention multiplied by history re-sends; a round trip between every step (#4); a session budget shared with `decide` (#13).

## Sound

The three-level fallback with `planner_requested` / `planner_used`; ADR-0013's rules referenced, not restated, the 2-attempt cap backstopped by the `practices` CHECK; the end rule's unattempted-stays-`candidate`; no graph persistence, one transaction per node, checkpoints between nodes; every call through `brain_call` / egress / budget / audit, no provider SDK or `FallbackModel`; re-rendering user parts from leaves and failing closed (the idea; see 1–2); parent interests gated by `CLOUD_PARENT_TEXT`; the TD-1 import order (httpx 0.28.1 installed); the prototype before the ADR with P9's fallback named; a broad test list; the free-text check honestly described. Not touched: catalog areas A, C1, D, E, J, C4.

# Word list: what backs `is_word` and the level band (reference collection)

Checked: 2026-10-22. Method: `tiered-research` (T1 = the dataset owner's own site, its licence text, OSF/PyPI/GitHub metadata read through their APIs; T2 = the peer-reviewed paper that describes a dataset; T3 = files downloaded and measured locally in a scratch directory, nothing installed into `.venv`; T4 = secondary, "reported" only) and `gather-code-references` for the library and dataset comparison. Every claim below traces to a row of §6. Rows marked *(inferred)* or *(not verified)* were not confirmed against a primary source.

Decision it serves: plan `docs/plans/active/2026-10-22-ai-led-study.md` → M0.2. ADR-0013 v2 (Definitions → `WordInfo`) needs `is_word(w)`: "the word is in the household lexicon or in the bundled frequency word list ADR-0017 §6.2 ranks with". ADR-0017 §6.2 ranks new items by "level band above the learner's (Cambridge YLE, SUBTLEX-UK children's frequency), then frequency". The learner is about 10 and reads children's books in English as a second language. The list is either bundled in the repository or fetched by `leafi doctor --download` into `models/` (gitignored) and used offline. No commercial use is planned; the repository may become public on GitHub.

What each role needs:

- **`is_word`** decides `fuzzy` (not a word: a garble or typo) against `substitute`/`inflection` (a real word) in ADR-0013. It needs **every inflected form** (walked, smiles, mice, horse's), both British and American spellings (books for children are published in both), and **no typos or chat tokens** ("teh", "asdf"), because a typo accepted as a word turns a `fuzzy` match into a real-word substitution. Frequency is not needed.
- **Level band** needs a graded scale that means something for a 7–12-year-old reader, per word form or per lemma (`lemmas(w)` already exists in `WordInfo`), and a frequency to rank within a band.

Terms used below:

- **Zipf** is log10(frequency per billion words); 1 is very rare, 7 is "the". 3 ≈ once per million words (W6).
- **Word form** is the spelling as it occurs (walked); **lemma** is its dictionary form (walk).
- **Share-alike (SA)** means a file adapted from the data must be released under the same licence. It binds the data file, not Leafi's code (*inferred* from the CC BY-SA 4.0 scope; not legal advice).

## 2. Findings

1. **No single list does both jobs.** The speller list (SCOWL) is clean and complete in inflections but has no frequency; the frequency lists either contain typos (wordfreq) or were never cleaned for spelling (SUBTLEX). CYP-LEX is the exception on cleanliness because it was filtered against SCOWL (W20), but its 105,694 types cover only words that occur in the 1,200 books.
2. **wordfreq fails `is_word`.** At Zipf ≥ 3 (its own "small" list) it accepts "teh"; the large list accepts "hte" and "asdf" (W12). ADR-0013's typed-typo example ("hosre") would still be caught, but common typos would become real-word substitutions. Its data is also frozen (W13).
3. **The SUBTLEX licences disagree.** The SUBTLEX-US OSF project states CC BY-NC-SA 4.0 (W27); wordfreq reports a by-e-mail permission for any purpose with two conditions (W11); SUBTLEX-UK's own pages state nothing (W24, W25). These are different owners' statements at different times; neither overrides the other here. Leafi's use is non-commercial, so NC is met, but SA would bind any bundled extract.
4. **ADR-0017 §6.2 names SUBTLEX-UK children's frequency, but CYP-LEX is the closer fit** for a child who *reads*: it is print from books UK children read, banded 7–9 and 10–12, and a substantial share of its words never occur on CBBC/CBeebies (W19, W20). It also carries the CBBC and CBeebies values as columns (W22), so nothing is lost by switching. The adult authors of SUBTLEX-UK (Brysbaert) co-authored CYP-LEX (W19).
5. **Cambridge YLE is the only graded list aimed at young learners of English as a foreign language**, which is this learner's situation, but it is small (~1,400 headwords across three levels), lists base forms only (needs `lemmas(w)`), and has no licence for redistribution (W29).
6. **The CYP-LEX licence covers CYP-LEX; its third-party columns are less clear.** The SUBTLEX-UK and CPWD columns inside the CYP-LEX CSVs come from datasets with no stated licence (W22, W24, W36). Dropping those columns from any bundled extract avoids the question *(inferred)*.

## 3. Recommendation

### 3.1 `is_word`

`is_word(w)` = casefold(w) in **household lexicon ∪ SCOWL size-60 `en_GB-ise` ∪ `en_US` (rel-2026.02.25) ∪ CYP-LEX word forms from the 7–9 and 10–12 bands**.

- SCOWL gives the clean, fully inflected core (111,066 forms, both spellings, measured, W3).
- CYP-LEX adds book words outside size 60, including character names and rarer forms (it was filtered against the full 658,235-word SCOWL, W20). A minimum count (for example `Count ≥ 3`) keeps one-off OCR survivors out; the threshold is a prototype check, not a measured value *(inferred)*.
- Not wordfreq (typos, W12), not SUBTLEX (unclean, unclear licence).
- `page_reads.alignment_versions` records `scowl-60-2026.02.25` and `cyplex-2024-03-21` as the word-list version.

Licence consequence:

- **SCOWL: bundle.** (a) Bundling the two text files (2 MB) in a public repo is allowed; the copyright notice and permission text (the part of SCOWL's `Copyright` file before `===`) must appear with them, for example as `leafi/data/wordlist/SCOWL-COPYRIGHT.txt` (W1). (b) Downloading at install time is also allowed, from the GitHub release (W4).
- **CYP-LEX: download, or bundle a trimmed extract with attribution.** (a) CC BY 4.0 allows bundling the files or an adapted extract (for example, word form, lemma, count, Zipf for 7–9 and 10–12, SUBTLEX/CPWD columns dropped) in a public repo, with attribution to Korochkina, Marelli, Brysbaert & Rastle (2024), a link to the licence, and a note that the file was modified (W16, W18). (b) `leafi doctor --download` can fetch `main_cyplex79.csv` and `main_cyplex1012.csv` (21.6 MB) from OSF into `models/` (W21); the extract is then built locally. Bundling the trimmed extract is the simpler offline story and is permitted; the size of that extract is not measured *(not verified)*.

### 3.2 Level band

Band = **Cambridge YLE level** (Starters < Movers < Flyers) when `lemmas(w)` meets a YLE headword; otherwise **CYP-LEX Zipf in the 7–9 band, then 10–12** cut into bands; rank within a band by CYP-LEX Zipf for the learner's age band.

- This needs ADR-0017 §6.2 to read "CYP-LEX children's-book frequency" in place of "SUBTLEX-UK children's frequency" (finding 2.4). SUBTLEX-UK CBBC values remain available as a CYP-LEX column if the owner wants a spoken-language signal.
- Kuperman AoA is a possible later tie-breaker for lemmas; not recommended now (adult raters, no stated licence, W33).

Licence consequence:

- **Cambridge YLE: do not bundle.** (a) No permission to redistribute was found; bundling the PDF or a headword list extracted from it is not covered (W29, W30). (b) Downloading the official PDF at install time (`leafi doctor --download`) for the household's own use, and parsing it locally into `models/`, does not redistribute it. The URL differs by country site and is fragile (W29, W31); `doctor` should report a missing file and let banding fall back to CYP-LEX alone. Whether the extracted headword list is itself protectable is a legal question not settled here.
- **CYP-LEX:** as in §3.1.
- **If SUBTLEX-UK is used directly** instead of through CYP-LEX: download only, and treat it as CC BY-NC-SA (finding 2.3); a bundled extract would have to be CC BY-NC-SA 4.0, and the SUBTLEX credit conditions apply.

### 3.3 Prototype must test

1. `is_word` on ADR-0013's examples: `house`, `horse`, `walked`, `smiles`, `mice` true; `hosre`, `teh` false; a CYP-LEX character name true.
2. The share of tokens on 10 real pages of the learner's books that `is_word` rejects (target: only names and true typos), with and without the CYP-LEX supplement, and at `Count ≥ 1, 3, 10`.
3. Load time and memory of the union set on Windows (expected about 150k strings) *(inferred)*.
4. Size of the trimmed CYP-LEX extract; decide bundle vs download from it.
5. YLE PDF parse: headword count per level and match rate of `lemmas(w)` against it on the same 10 pages.

## 4. Rejected

- **wordfreq as `is_word`**: typos and chat tokens inside its lists (W12); data frozen (W13); SA on any bundled extract (W10).
- **hunspell dictionaries**: same words as SCOWL but in stem + affix form, needing an engine or an expansion step; en_GB is LGPL (W7, W9).
- **Oxford Children's Corpus**: no access without OUP permission (W32).
- **CPWD**: search interface only, 2003 site (W36); its values are in CYP-LEX.
- **SUBTLEX-US**: adult American film, CC BY-NC-SA (W27).
